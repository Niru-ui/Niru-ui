## 🚀 Featured Projects

### 🔎 [PacketMortem](https://github.com/Niru-ui/PacketMortem)

A Python-based network-forensics and threat-investigation platform for offline PCAP analysis and live packet capture.

- Five threat detectors with MITRE ATT&CK mapping
- Risk, severity, and confidence scoring
- Separate offline and live investigation findings
- Professional HTML dashboards and JSON reports
- SHA-256 evidence-integrity verification
- Encrypted report storage in Amazon S3
- Tested and deployed on Amazon EC2
- Automated testing with pytest and GitHub Actions

### 🔐 [AWS Cloud Security Auditor](https://github.com/Niru-ui/aws-cloud-security-auditor)

An automated security-auditing tool for identifying AWS infrastructure misconfigurations.

- Audits IAM, S3, EC2 Security Groups, and CloudTrail
- Calculates an overall security score
- Provides remediation recommendations
- Generates HTML and JSON security reports
- Tested against a live AWS environment

### 💻 [TechnicalClusterManager](https://github.com/Niru-ui/TechnicalClusterManager)

A Django application for submitting, monitoring, and displaying HPC workloads through Slurm.

- Django-based web interface
- Slurm job submission and monitoring
- Linux and HPC integration
- Cloud deployment experience
